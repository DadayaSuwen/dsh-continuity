# 导入自己的对话

[English](import.en.md) · [手机入口](mobile.md) · [记忆审阅](memory.md)

> Host 导入主流程已有实现；原生界面 **Experimental / 未验收**。官方 v3 合成夹具的实际测试，不等于任意真实 App 导出或手机流程都已通过。

## 官方 ZIP 优先

1. 在自己已安装的 DeepSeek App 查看是否提供历史导出。头像 / 设置 / 数据管理只是检查位置示例，不是各版本必有菜单；没有导出时复制 / 分享文本备用。
2. 直接选 ZIP，保持原件不变，不先解压。核对当前连接的 DSH Host、角色 / 故事、保存位置和上传限额。
3. 查看解析报告：支持的对话、消息树、分支、附件引用和警告。预览仅 Host 暂存，尚未保存原始资产或创建正式对话。
4. 勾选支持对话后保存并迁移。**只选一段也保留整个 ZIP**，其中其他对话可能含私密内容。
5. 对照新增 / 重复 / 失败结果。再导入相同来源时账本可复用已核验正式对话；多对话部分失败不等于全部回滚。
6. 审閱原句记忆候选；确认前不进入角色恢复资料。

## 保留与转换不同

- 当前官方门禁是 `export_format_version: 3`，其他版本明确报错。
- 默认祖先链跟随 `current_message_id`，缺失/null/无命中则取最大 message id；不是“最新 FINISHED 分支”。FINISHED 控制回复是否转换。
- 原 ZIP 保留全部分支和未知内容；正式对话只有选中链。其他 leaf 提交和记忆联动为 Experimental。
- 图片可能由官方服务规范化保存；非图片缺原正文时只有文件卡/元数据。不保证所有附件进入正式对话。
- 未完成回复、模板、撤回轮、未知片段按官方规则排除/报告；原件保留不等于所有文本进入模型。
- 原标题/时间值留在原件，正式标题可规范化，日期解析到毫秒。未知历史不伪造。

详细依据：[本地预检](../../src/migration/preview.ts)、[提交](../../src/migration/migration.ts)、[固定官方转换](https://github.com/DeepSeek-ai/deepseek-harness/blob/ca33fd6843b205e279c7ccb6cb73a472c78f5760/packages/experimental/deepseek-chat-import/src/conversation.ts#L90-L171)。

## 应急 TXT / Markdown / JSON

复制的文本至少标说话者：

```text
用户：角色：你叫林，沉稳温柔。
助手：我会陪你继续灯塔的故事。
用户：剧情：银钥匙在我手里，下一步寻找船长。
```

未标注部分保留 `unknown`，当前需在原文件修正后重新上传再提交。轮次从用户开始、最多接一条助手回复；应急日期缺失保留 null。该通道是一段线性文本，不恢复树、图片正文、原生工具事件或全部平台字段。通用 JSON 请使用[已定义的 messages 格式](../architecture/MIGRATION_FORMAT.md)，不是任意 JSON 自动兼容。

## 报错与数据范围

默认上传 128 MiB；预检限制展开总量、条目、压缩比、路径、CRC、UTF-8 和 JSON 深度。ZIP64/加密/分卷不受支持。Host 一次一个暂存，15 分钟过期；先清除暂存再选下一文件。取消/中断后已持久化记录可能仍在，应核对回执再重试。

源删除只移除插件原始资产，不删除官方 Session、附件或记忆。先[备份](backup.md)再删除。导入和规则提取无默认外部模型调用；后续发送对话才使用明确选择的模型服务。

# 备份、恢复与删除范围

[English](backup.en.md) · [导入](import.md) · [记忆](memory.md)

> 当前为 **package v1**。Host 导出/恢复已有实现，手机系统下载和原生完整操作流程 **Experimental / 未验收**。checksum 不等于加密或签名。

## 保存角色备份

1. 选择正确的角色档案 / 故事，读取已保存资料。
2. 在“备份与管理”下载角色备份。文件含私密聊天原件和记忆，交由你选择的位置保管。
3. 核对浏览器确实保存了文件；保留原 ZIP、原备份，不手工改字段或摘要。
4. 在删除来源前备份；如果还保留引用该来源的记忆，先删来源再导出的包可能缺证据而恢复失败。

界面称“完整角色备份”，其“完整”只指本插件当前分区资产，不是完整 Host 或完整官方对话备份。[当前下载实现](../../src/ui/Panel.tsx)、[Host 导出](../../src/routes.ts)

## v1 包含什么

| 包含                                                          | 不包含                                               |
| ------------------------------------------------------------- | ---------------------------------------------------- |
| 当前归属分区的全部原始 sources、原 bytes base64 与预览        | 正式 DSH Session 日志及迁移后继续聊的新消息          |
| candidate / active / conflict / superseded 等记忆、版本、引文 | 独立官方附件对象库                                   |
| 删除指纹、分区 revision、导出时间、checksum                   | Session bindings、import ledger、模型凭据、Host 配置 |

当前原始字节总包含，没有“只导摘要”开关。一个原 ZIP 可含未选中的对话；它们仍随原字节进入备份。备份是明文 JSON / base64，base64 不是加密。

## 恢复

1. 在目标 Host 选择明确的目标角色 / 故事与用户归属。
2. 选择 v1 备份。Host 校验 schema、payload 摘要、原字节摘要、分区一致性与字面出处。
3. 读取恢复结果。相同 id/记录复用，同 id 不同内容报冲突；不静默覆盖目标记忆。
4. 恢复的是来源和记忆，不自动产生原正式 Session。需要正式历史时从原 ZIP 重新导入；只用记忆可新建对话。
5. 在新对话核对已确认资料后再继续。候选仍保持候选，不因恢复而自动确认。

当前来源写入与记忆更新不是全包事务；出现错误可能已存部分来源。返回 memory_count 是合并后总数，不是新增数。[package 实现](../../src/migration/package.ts)

默认 Web 恢复受 Host 上传限额约束；base64 + 预览会令备份大于原件，128 MiB ZIP 不保证它的备份能从128 MiB入口恢复。先小样本核验，保留原 ZIP；大包流式处理为 **Planned**。

## checksum 的含义

SHA-256 检测摘要与 payload / 原始字节不匹配，帮助发现传输/保存损坏。没有密钥、没有数字签名、没有发送者身份认证；有意修改并重新计算摘要仍能通过这一检查。当前 v1 不提供加密或签名。未来 schema 转换与加密/签名为 **Planned**，不把 Node/插件升级宣传为任意版本自动迁移。

## 各种删除互不替代

| 操作                | 当前效果                                                                                 |
| ------------------- | ---------------------------------------------------------------------------------------- |
| 删除单条 / 全部记忆 | 移除对应分区记忆并记当前指纹墓碑；原始资产、正式对话保留                                 |
| 删除原始资产        | 删除插件 source；已确认记忆 / 引文、import ledger、正式 Session 与附件保留，来源全文消失 |
| 卸载插件            | 停止并关闭服务，默认保留持久数据                                                         |
| 删除正式对话 / 附件 | 当前官方 SessionPersistence / Attachment 缺删除 API，不由 source 删除模拟                |

编辑/删除记忆不删除旧日志里的资料快照或模型已回答内容。处理完整 Host 数据需区分这四类资产，不把插件按钮视为全部数据清除。数据原本保存在当前连接 Host，手机浏览器不是它的权威库。
